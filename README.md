# ГРЕЧКА 2026 — как подключить бесплатную онлайн-базу (Supabase)

Фронтенд (`index.html`, `script.js`, `style.css`) уже умеет работать с API
(`/api/register`, `/api/vote`, `/api/videos`, админка). Раньше эти запросы
никуда не вели. Теперь для них есть сервер `server.js`, который хранит всё
в **Supabase** — бесплатной облачной PostgreSQL-базе.

Что база делает по вашим требованиям:
- **Сохраняет имя пользователя** — таблица `voters` (имя + токен, чтобы
  голос могли менять только «от своего имени», без пароля).
- **Показывает результат голосования** — таблица `votes`; в админке (#admin)
  на вкладке «ВЫБОР ЛЮДЕЙ» видно голоса по номинациям и кто за кого проголосовал.
- Видео роликов хранятся в Supabase Storage (бесплатно 1 ГБ).

---

## Шаг 1. Зарегистрироваться в Supabase (это «куда залогиниться»)

1. Откройте **https://supabase.com** → **Start your project** → войдите через
   GitHub / Google / email. Это бесплатно, карта не нужна.
2. **New project** → название любое (например `grechka`), пароль от БД —
   придумайте и сохраните, регион выберите ближайший (например Frankfurt).
3. Подождите ~2 минуты, пока проект создастся.

## Шаг 2. Создать таблицы

1. В дашборде слева: **SQL Editor** → **New query**.
2. Скопируйте целиком содержимое файла `schema.sql` из этой папки → **Run**.
   (Создаст таблицы `voters`, `videos`, `votes`, `admins` и приватный bucket
   `videos` для роликов.)

## Шаг 3. Взять ключи

Слева: **Project Settings (шестерёнка)** → **API Keys** (или Data API):
- **Project URL** → это `SUPABASE_URL` (вида `https://abcd.supabase.co`)
- **service_role secret** → это `SUPABASE_SERVICE_KEY` (начинается с `eyJ…`)
  Нажмите Reveal / Copy. ⚠️ Этот ключ НЕ должен попасть в браузер или в git —
  он только для сервера.

## Шаг 4. Настроить `.env` и запустить локально

```bash
cp .env.example .env      # затем отредактируйте .env своими значениями
npm install               # ставит express, supabase-js, dotenv, ws
ADMIN_PASSWORD=ваш-пароль node server.js   # или впишите пароль в .env
```

Откройте **http://localhost:3000** — сайт работает с живой базой:
пользователь вводит имя (сохраняется в БД), голосует, а вы смотрите
результаты в **#admin**.

## Шаг 5. Опубликовать в интернет (тоже бесплатно)

Код фронтенда менять не нужно — сервер сам раздаёт и сайт, и API.

1. Запушьте этот репозиторий в **github.com** (приватный, `.env` в git не попадает
   — он уже в `.gitignore`).
2. Зайдите на **https://render.com** → Free account → **New → Web Service** →
   подключите репозиторий.
3. Build Command: `npm install`, Start Command: `node server.js`.
4. В разделе **Environment Variables** добавьте: `SUPABASE_URL`,
   `SUPABASE_SERVICE_KEY`, `ADMIN_PASSWORD`.
5. Render даст бесплатный адрес вида `https://grechka.onrender.com` —
   его и раздавайте гостям. (На бесплатном тарифе сервис «засыпает» без
   запросов — первый заход занимает ~30 сек, потом работает нормально.)

Лимиты бесплатных тарифов, которых хватит на вечеринку: Supabase — 500 МБ БД
+ 1 ГБ Storage, Render — 750 часов/мес free.

## Полезное

- Сбросить всё перед церемонией: SQL Editor →
  `truncate votes; truncate voters;`
- Посмотреть данные руками: Supabase → **Table Editor** → выбрать таблицу.
